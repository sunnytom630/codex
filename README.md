# 河北 2027 志愿参考工具

从用户提供的 `河北2027志愿参考工具.zip` 原样导入的静态网页，面向河北物理、化学、生物考生。支持按历史分数和参考位次筛选院校专业、冲稳保经验分档、备选收藏排序和 CSV 导出。

## 本地运行

无需安装第三方依赖。使用 Python 3 在仓库根目录启动静态服务器：

```sh
cd /workspace/codex
python -m http.server 8000 --bind 127.0.0.1
```

在个人电脑上运行时，将工作目录替换为自己的仓库路径，在浏览器打开 `http://127.0.0.1:8000`。也可直接打开根目录的 `index.html`；浏览器对本地文件的收藏存储行为可能有所不同。

## 文件

- `index.html`、`style.css`、`app.js`：页面、样式和交互。
- `engine.js`：筛选与经验分档逻辑。
- `data.js`：随附件提供的数据快照。
- `assets/`：离线字体及 OFL 许可证。
- `使用说明.md`：附件原始说明，原样保留。

原始说明中的 `dist/index.html` 在本仓库对应根目录的 `index.html`。压缩包未附带 `data/raw`、`data/audit.json`、`build_data.py` 或 `test_engine.cjs`，因此目前不能按原说明重建数据或运行其原始测试。

## 验证与使用范围

导入时通过 Chromium 浏览器验证了两个历史年份的分数筛选、关键词和办学性质筛选、冲稳保标签、收藏持久化、排序和 CSV 导出；另对两个年份各 400–690 分的全部 582 组输入执行了引擎检查。

这些检查验证程序运行，不代表已独立核验历史数据或选科匹配的准确性。原始数据附件和审计文件缺失，数据来源仍需另行复核。2027 招生计划等信息尚未接入；经验分档不代表录取概率，也不保证录取。使用前请核对官方招生计划、章程及当年规则。

收藏保存在当前浏览器的本地存储中；更换浏览器或清理存储前请导出备选表。本项目无需账号、API 密钥、数据库或后台服务。
