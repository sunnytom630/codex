# 河北志愿罗盘

面向2027年河北考生的专业探索与官方选科参考记录筛选系统。静态网页，无服务端问卷存储。

## 功能

- 问卷：合法3+1+2选科组合、学制、深造意愿、10个兴趣任务、能力优势、目标和明确底线。
- 42个专业探索样本，解释匹配分、关键兴趣、核心任务冲突和待核事项；信息不足不强行推荐。
- 91,789条去重后的2027年河北官方院校专业选科参考记录，2449所院校，本科与高职（专科）均可检索。
- 院校专业候选、调整顺序、最多4个专业对比、打印及CSV导出。
- 可选导入带来源的河北历史位次CSV。仅连续2024—2026三年同科类同名专业数据进行区间比较，不给录取概率。

## 数据与边界

选科表发布页：https://gaokao.chsi.com.cn/gkxx/zc/ss/202502/20250213/2293354258.html

官方分发附件：https://t4.chei.com.cn/news/file.do?attach=true&hist=false&id=2293354259&method=downFile

原表标题、下载来源和SHA256保存在dist/requirements.json的meta中。去掉完全重复行，保留科目要求原文。专业探索索引仅使用本科层次完全同名记录，不以专科条件替代本科条件，不将专业类自动映射到具体专业。

原表是选科参考，不等于2027年实际在河北的分科类招生计划。没有学费、校区或录取位次时明确显示待核，不自动编造。河北普通本科批模式及96个上限参考已公布2026年规则，2027年仍须复核。

课程、岗位和权重为人工整理的探索规则，不是经过效度验证的职业测评。兴趣权重70，已填写的优势20、目标10，缺失部分不计入分母。希望本科就业且样本标记为部分目标岗位常需深造时，降低10分优先度，但不认定该专业不能本科就业。专业核心兴趣已知不足50%、无明确高兴趣或总分低于45，不列优先推荐。每个专业样本列出实际体验建议，鼓励据体验更新回答。

## 本地运行与检查

用HTTP静态服务打开dist/index.html。执行node --test tests/*.test.js可验证选科、不同画像排序、底线排除、未知信息处理、官方数据查询及历史位次对比。

问卷及候选仅保存在浏览器localStorage；导入历史数据仅在当前会话内使用，不上传。

## 96志愿工作台（第一期，2026-10-29）

新增独立工作台，保留原有专业探索。历史原表共102,539条，覆盖2023—2026物理/历史本科批，原始年度代号、最低投档分、同分排序项和备注保留。来源链接、整理时间、原始文件SHA256在数据工作台可查。学校所在地来自2026教育部高校名单，共2952所；所在地不代表实际就读校区。

扫描版一分一段采用OCR提取，只把相邻分数累计差等于本档人数的记录用于位次转换。101,110条投档记录可映射到同分段位次区间。未识别或不一致的分数档不补齐，原始分数仍可查。此校验不等于独立人工审计，区间也不是末位投档个人精确位次。

- 预选草案：2027选科参考与2024—2026连续三年同名项目历史匹配；专业方向括号保留，存在多条同名历史记录时排除。筛选位次、专业关键词、学校所在省、学费与学制待核、民办、合作标识和每校数量上限。最多96项，优先保留指定数量的历史余量项目。阈值不是录取概率，数量不足不放宽条件。
- 已核验参考方案：要求当年河北普通本科批正式项目完整，来源、代码、实际校区、人数、学制、学费、选科、语种、体检与单科规则均经本机人工复核，并由本人逐项确认资格。任一关键字段变化使本人确认失效。此记录不是平台独立专家审核。
- 支持锁定、排序、移除、编辑分支、最多12份快照、取舍笔记、CSV与打印报告、数据备份。工作台用IndexedDB，仅本浏览器保存，无云端同步。恢复外部备份仅恢复条件与待审计划，重新核验并生成方案；不直接信任备份的已审状态。
- 数据工作台：年度计划CSV暂存校验、待审队列、人工复核与撤销、原表检索、来源台账、操作记录与扫描质量说明。
- 2026历史区间覆盖检查使用2023—2025前置数据，再检查2026实际区间重叠，严格隔离目标年。仅用于观察历史区间稳定性，不能表达个人录取准确率，跨年选科政策与计划变化未建模。

### 尚未完成的正式服务能力

2027完整招生计划尚未接入。2026仅有金华职业技术大学18条公开计划样本，缺年度代码、校区和章程核验，默认待审。当前不是可直接照抄提交的2027正式填报服务；尚无全量年度计划运营、独立双人审核、跨设备账户与权限、经校准的录取模型或专家咨询。未来正式启用仍需接入年度计划、一分一段、章程及限制，复核当年河北政策，并完成持续更新与人工审计。

静态数据按年度分卷，单文件低于25MiB。生成脚本prepare-planning-data.py需要原始文件data/raw及已处理OCR TSV（临时工作目录），原始文件不随网站部署。数据台账保留来源和校验值。


## 本仓库更新（第二版 2.1）

此版本替换第一版页面。GitHub Pages 继续使用 `main` 分支的根目录，无需更改发布设置；根目录入口加载 `dist/` 中的静态文件，`.nojekyll` 避免额外站点构建处理。可从 Git 历史找回第一版。第一版浏览器收藏不会被删除，但不会自动迁移为第二版方案。

新增历史分数换算参考位次，使用内置2023—2026物理/历史一分一段表中已校验的精确分数档；缺档不插值、不采用“某分及以上”汇总档。默认取同分段末位，显示参考年份及区间。这不是2027位次预测，切换科类会清除换算结果；切换至已核验模式也须重新填写位次。

专业探索底线与工作台联动：对42个完全同名样本检查核心学习任务冲突，冲突项目自动排除。不对相近专业、方向或专业类强行推断；存在底线且专业尚未映射时，默认不进入自动方案；仅在用户勾选允许任务待核专业后才选入，并列出待核事项。可以明确填写专业关键词缩小范围，或手动排除其他项目。

修改选科、底线或筛选条件后，历史快照仍可查看，但显示须重新生成的提示；CSV和打印报告保留参考位次来源及旧快照状态。

**本次未添加2027招生计划。** 当前以2027选科参考、2023—2026历史投档资料进行预选，不能作为正式填报表。数据附件和OCR中间文件未随源代码提供，不能仅凭内置校验值认定数据已经独立核准。

开发验证：`npm test`。运行：`npm start`（静态服务根目录为仓库根目录，端口8765）；也可在仓库根目录运行 `python3 -m http.server 8000` 验证 GitHub Pages 根入口。需要现代浏览器，直接双击HTML可能无法加载模块和JSON，请使用HTTP服务器。

浏览器存储修复：方案快照只保存入选项目、条件、历史依据与排除原因统计，不再重复存储全部未入选候选；加载旧工作台时会清理快照中的冗余候选。最多保留12份快照，可导出备份。
